One funny single-line reply from a hopeless tech support agent to a desperate customer, for the [Have You Tried Turning It Off?](https://make.fun/bounty/u-motasimfuad-have-you-tried-turning-it-off-154a938b) bounty on [make.fun](https://make.fun). The agent applies the classic reboot to the wrong target: instead of the computer, he cheerfully tells the customer to turn *themselves* off and on again.

## Run it

```sh
python3 main.py
```

This writes the entry line to `/output/entry.txt` (and, best effort, to `entry.txt` in the repo root). The program is deterministic: every run produces the same bytes.
